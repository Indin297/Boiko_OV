## Введение

Данное руководство описывает процесс создания **собственного генератора статических сайтов (SSG — Static Site Generator)** на платформе Node.js. Руководство рассчитано на начинающих разработчиков и содержит пошаговые инструкции, примеры кода и схемы.

**Цель проекта:** разработать программу, которая превращает EJS-шаблоны в готовые HTML-страницы, пригодные для публикации на любом веб-сервере.

**Задачи:**
- Изучить принципы работы статических генераторов.
- Освоить Node.js, npm и шаблонизатор EJS.
- Реализовать основной движок генератора.
- Добавить творческую модификацию — автоматическую навигацию.
- Оформить проект в виде репозитория на GitHub.

## Что такое статический генератор сайтов

**Статический генератор сайтов (SSG)** — это программа, которая на основе шаблонов и данных создаёт готовые HTML-файлы. В отличие от CMS (например, WordPress), SSG не требует базы данных и не формирует страницы «на лету» — все страницы генерируются заранее.

### Преимущества SSG

| Преимущество | Описание |
|--------------|----------|
| **Скорость** | Готовые HTML-файлы отдаются мгновенно, без запросов к БД |
| **Безопасность** | Нет базы данных — нечего взламывать |
| **Простота хостинга** | Можно разместить на GitHub Pages, Netlify и т.п. |
| **Версионирование** | Контент хранится в Git, легко откатить изменения |
