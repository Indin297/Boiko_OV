## Вариативная часть задания

**Node.js: Build a static site generator in 40 lines with Node.js**

В рамках вариативной части разработан генератор статических сайтов на Node.js с использованием библиотек `ejs`, `fs-extra` и `glob`. Генератор читает EJS-шаблоны, оборачивает их в общий layout и сохраняет готовые HTML-файлы в папку `site/`.
