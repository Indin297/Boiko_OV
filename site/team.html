Участники проекта

Бойко Олег Вячеславович

Роль: автор проекта, разработчик, тестировщик.

Личный вклад:

  • Изучение принципов работы статических генераторов сайтов.
  • Установка и настройка Node.js, Visual Studio Code и Git.
  • Разработка основного кода генератора (build.js).
  • Создание шаблонов страниц (.ejs) и общего каркаса (layout.ejs).
  • Создание блоков header.ejs и footer.ejs.
  • Разработка стилей сайта (style.css).
  • Реализация творческой модификации — автоматической навигации.
  • Написание документации и подготовка отчёта.
  • Ведение репозитория на GitHub.

Использованные инструменты

  • Node.js — платформа для запуска JavaScript.
  • npm — менеджер пакетов.
  • Visual Studio Code — редактор кода.
  • Git — система контроля версий.
  • GitHub — платформа для размещения репозитория.
